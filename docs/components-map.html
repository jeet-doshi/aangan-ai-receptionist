Components Map: Aangan Studio AI Receptionist

Every phone enquiry answered within minutes, day or night; qualified against Nikhil's rubric; the worthwhile ones reach a designer with everything already asked.

1 · Trigger

A call comes in

What starts the workflow?

Inbound enquiry call LIVE
  • Answered by the Vaani Voice AI agent, 24×7, including the ~33% that arrive outside 10am–7pm
  • Tested via Vaani web call (no phone number bought)
Simulated call DEMO
  • In-app form with one-click scenarios
  • Always labelled; never shown as a real call
Scope
  • Phone channel only
  • WhatsApp + web form: same pipeline later
2 · Input

What we capture

What data does the system receive?

From the caller
  • Name, phone, new vs existing client
  • Project type + carpet area
  • Site location
  • Timeline / deadline
  • Budget, only if volunteered
  • Decision-maker status
  • Pricing question? Complaint / urgency?
Vaani webhook LIVE
  • call_postprocessing event: summary, transcript, extracted entities, dispositions, duration
  • Secret-authenticated
3 · Context

What it knows

What rules and knowledge guide it?

qualified.md
  • Nikhil's 5 criteria: real project, Pune/PCMC, realistic timeline, budget band, decision-maker
services.md
  • Residential + offices/clinics/studios ≤ ~3,000 sq ft
  • Exclusions: structural, decor-only, furniture, restaurants, hotels, retail, gyms
  • Design 3–4 wk · execution 8–16 wk
pricing.md
  • One approved pricing line; no number, ever
40 Sep enquiry transcripts
  • 20 phone calls → demo seed + test set
4 · Processing

Prepare the data

How is raw input made usable?

Webhook handling
  • Verify secret
  • Record only call_postprocessing; ignore the ~10 lifecycle events
  • Duration ms → s
Normalise fields
  • Free text → categories ("3 BHK" → full home)
  • Fix speech-to-text slips ("Banner" → Baner)
Fill gaps from summary
  • Location, timeline, owner, area inferred from the caller's own words
  • Every inferred field flagged "verify"
5 · AI + decision

Think & decide

Where does judgement happen?

Vaani LLM voice agent
  • Converses, asks one direct follow-up, summarises, extracts entities
Rules engine ₹0 / CALL
  • ① Escalation check first: existing-client complaint, unresponsive designer, urgent request
  • ② 5 criteria: pass / fail / unclear
  • ③ Unclear 1–3 → one question; 1 fail → specific decline; 2+ → graceful decline
  • ④ Pricing guard on every reply
6 · Output

Who gets what

What happens as a result?

Caller
  • Approved reply, timelines explained, never a price
Designer: Telegram LIVE
  • 🟢 Qualified lead: full handoff note
  • Marked "sent" only when Telegram confirms
🔴 Urgent escalation
  • Existing-client complaints → senior team instantly; never an "unqualified lead"
Nikhil: dashboard LIVE
  • Supabase call records
  • Funnel, outcomes, decline reasons
  • Cost per call & per qualified lead

✂ The Cut: no price quoting

Nikhil asked the system to "quote our standard per-square-foot pricing". pricing.md says no number may ever be quoted, so this was deliberately not built. Every reply passes a pricing guard; pricing questions get only the approved line, and are not disqualifying.

⚑ Flagged for Nikhil: timeline rules conflict

services.md: ≥ 6 weeks. qualified.md / T07: 8–10 weeks. Design + execution: ≥ 11 weeks. < 6 wk declined; 6–10 wk sent to human review, not silently decided.

Why Telegram, not email

  • Designers are on site, on phones: instant push
  • One group chat: no lead stuck in one inbox
  • Free bot, 5-minute setup
  • Speed is the point: < 1 hr reply converts 4×

Honesty guardrails

  • Demo / simulated / live calls always badged
  • "Sent" only on confirmed delivery
  • Costs labelled as estimates until real rates are set
  • Inferred fields marked for the designer to verify
